**روترلینک (RouterLink)** یک پلتفرم جامع، بسیار سبک و سازمانی برای مدیریت و ارائه خدمات فیلترشکن و VPN امن است که به طور اختصاصی برای اجرا در **کانتینرهای لینوکسی میکروتیک (MikroTik RouterOS 7 Linux Containers)** طراحی و پیاده‌سازی شده است.

این سیستم شامل ۴ بخش هماهنگ و یکپارچه است:
1. **اسکریپت‌های اتوماسیون میکروتیک**: راه‌اندازی، آپدیت و بکاپ بدون تداخل با تنظیمات روتر.
2. **هسته بک‌اند (FastAPI)**: مدیریت احراز هویت، نشست‌ها، سیستم حسابداری مصرف ترافیک و سرورهای پروتکل (OpenVPN و WireGuard).
3. **پنل مدیریت تحت وب (WebUI)**: داشبورد بلادرنگ، مدیریت کاربران، صدور کانفیگ و QR کد.
4. **اپلیکیشن کلاینت اندروید (Native Android)**: اتصال تک‌لمسی، بدون نیاز به تنظیمات دستی و با تونل واقعی سیستم‌عامل (`VpnService`).

## 🌟 ویژگی‌های کلیدی

### 🖥️ سازگاری کامل با کانتینرهای MikroTik RouterOS 7
- **نصب کاملاً خودکار و بدون تداخل (Non-destructive)**: اسکریپت `install.rsc` یک Bridge اختصاصی (`bridge-routerlink`) و VETH می‌سازد و هیچ‌کدام از بریج‌ها، فایروال‌ها یا مسیرهای روتینگ شبکه فعلی شما را تغییر نمی‌دهد.
- **مصرف بهینه منابع سخت‌افزاری**: مبتنی بر Alpine Linux 3.20 با حجم ایمیج کمتر از ۹۰ مگابایت و مصرف رم کمتر از ۷۵ مگابایت (مناسب برای دستگاه‌های RB750Gr3 ،hEX S ،CCR2004 و ماشین‌های مجازی CHR).
- **پایداری قطعی اطلاعات**: دیتابیس SQLite در حالت WAL، کلیدهای رمزنگاری و فایل‌های کانفیگ به صورت مستقیم روی مسیر `/routerlink/data` در حافظه دائمی روتر ذخیره می‌شوند و با ری‌استارت شدن یا حذف کانتینر پاک نمی‌شوند.

### 🛡️ مدیریت پروتکل‌های مدرن VPN (PAL)
- **OpenVPN TCP (پیش‌فرض پورت 8443)**: بهینه‌شده برای عبور از فیلترینگ شدید و دیوارهای آتش با امضای ترافیک TLS و سایفرهای استاندارد AES-256-GCM.
- **OpenVPN UDP (پورت 1194)**: سرعت بالا برای استریم و بازی.
- **WireGuard (پورت 51820)**: سبک‌ترین و سریع‌ترین پروتکل مدرن با رمزنگاری Curve25519 و تبادل خودکار کلیدها.

### 📊 حسابداری بلادرنگ و قطع خودکار دسترسی (Worker)
- محاسبه دقیق حجم دانلود و آپلود هر کاربر در هر سشن.
- قطع اتصال آنی به محض اتمام حجم مجاز یا سررسید تاریخ انقضا.
- کنترل سقف اتصالات همزمان (Max Concurrent Devices).

### 💻 پنل وب مدرن و تعاملی
- داشبورد مانیتورینگ منابع سرور و پهنای باند مصرفی با نمودارهای زنده SVG.
- ایجاد، ویرایش، تمدید و حذف کاربران و دانلود مستقیم کانفیگ `.ovpn` و `.conf`.
- ایجاد خودکار **کد QR اختصاصی** برای ورود سریع در اپلیکیشن اندروید.
- مدیریت اتصالات فعال با قابلیت قطع کاربر (Kill Session) با یک کلیک.
- امکان دانلود فایل پشتیبان و ایمپورت مستقیم از مرورگر.

### 📱 اپلیکیشن اندروید نیتیو (Kotlin + Jetpack Compose)
- بدون نیاز به فایل کانفیگ دستی؛ فقط با اسکن QR کد ورود یا وارد کردن آدرس سرور.
- اتصال امن از طریق سرویس داخلی `android.net.VpnService` (بدون قطعی و بدون نمایش وضعیت جعلی).
- نمایش سرعت لحظه‌ای، حجم مصرفی، مانده اشتراک و زمان اتصال.
- سیستم هوشمند Auto-Reconnect هنگام تغییر شبکه از Wi-Fi به همراه (Mobile Data).

## 🚀 نصب سریع ۱-کلیکی روی میکروتیک

برای نصب روترلینک روی میکروتیک با RouterOS 7.10 یا بالاتر، کافیست وارد ترمینال روتر (یا نرم‌افزار WinBox) شده و دستور زیر را اجرا کنید:

```routeros
# ۱. دانلود اسکریپت نصب خودکار
/tool fetch url="https://raw.githubusercontent.com/<نام-کاربری-گیت‌هاب>/RouterLink/main/mikrotik/install.rsc" dst-path="install.rsc"

# ۲. اجرای نصب
/import install.rsc
```

### عملیات انجام شده در نصب خودکار:
1. بررسی نسخه RouterOS (حداقل 7.10) و وجود پکیج container.
2. ایجاد اینترفیس `veth-routerlink` با آی‌پی `172.28.0.2/24`.
3. ایجاد بریج ایزوله `bridge-routerlink` با آی‌پی گیت‌وی `172.28.0.1/24`.
4. ایجاد پوشه پایدار `/routerlink/data` روی دیسک روتر.
5. اضافه کردن رول‌های NAT پورت‌های 8080 (وب)، 8443 (اوپن‌وی‌پی‌ان)، 1194 و 51820 (وایرگارد).
6. دریافت آخرین ایمیج داکر روترلینک از رجیستری گیت‌هاب (GHCR) و اجرای کانتینر.
7. چاپ آدرس ورود به پنل تحت وب در لاگ و خروجی ترمینال.

## 💻 راهنمای استفاده از پنل مدیریت

1. در مرورگر خود آدرس روتر را به همراه پورت 8080 باز کنید:
   ```text
   http://<Router-IP>:8080
   ```
2. در اولین ورود، **ویزارد نصب (Setup Wizard)** نمایش داده می‌شود:
   - نام کاربری مدیر (پیش‌فرض: `admin`)
   - رمز عبور دلخواه مدیر
   - آی‌پی عمومی یا دامنه سرور (Public IP / DDNS Hostname)
3. پس از ذخیره، وارد داشبورد اصلی می‌شوید:
   - **مدیریت کاربران (User Management)**: تعریف نام کاربری، رمز، حجم مجاز (گیگابایت)، تاریخ انقضا و تعداد دستگاه همزمان.
   - **تولید QR کد**: برای هر کاربر روی آیکون بارکد کلیک کنید تا کد اتصال سریع تولید شود.
   - **مدیریت پروتکل‌ها**: فعال/غیرفعال کردن پروتکل‌ها، تغییر پورت و مشاهده لاگ دیمن‌ها.
   - **اتصالات آنلاین (Live Sessions)**: مشاهده آی‌پی ریموت، نرخ سرعت و قطع ارتباط با یک کلیک.
   - **پشتیبان‌گیری (Backup)**: خروجی گرفتن و بازیابی دیتابیس با پسوند `.json`.

## 📱 راهنمای اپلیکیشن کلاینت اندروید

### دریافت فایل نصب (APK)
فایل آماده برنامه کلاینت با نام `RouterLink-Release.apk` در تب **Releases** ریپازیتوری گیت‌هاب برای دانلود قرار دارد.

### مراحل اتصال کاربر:
1. اپلیکیشن **RouterLink** را روی گوشی اندروید نصب کنید.
2. برنامه را باز کرده و روی دکمه **Scan Setup QR Code** بزنید و دوربین را مقابل QR کد در پنل وب بگیرید (یا آدرس سرور و اطلاعات کاربری را دستی وارد کنید).
3. پروتکل دلخواه خود را انتخاب کنید (پیشنهاد ما برای اینترنت‌های محدود شده: **OpenVPN TCP 8443**).
4. روی دکمه بزرگ **CONNECT** بزنید و درخواست مجوز VPN سیستم‌عامل را تأیید نمایید.
5. به همین سادگی تونل امن برقرار شده و سرعت دانلود/آپلود و حجم باقی‌مانده به شکل زنده نمایش می‌یابد.

## 🚀 ارسال روی گیت‌هاب و بیلد خودکار کانتینر و APK

پروژه به گونه‌ای طراحی شده که با ارسال آن روی گیت‌هاب، **گیت‌هاب اکشنز (GitHub Actions)** به صورت ابری و کامپایل شده موارد زیر را می‌سازد:
- **کانتینر داکر چندمعماری (`linux/amd64` و `linux/arm64`)** و انتشار روی `ghcr.io`.
- **فایل نهایی کلاینت اندروید (`RouterLink-Release.apk`)**.
- **بسته فشرده اسکریپت‌های میکروتیک (`routerlink-mikrotik-scripts.zip`)**.

### روش اول: استفاده از اسکریپت اتوماتیک (سریع‌ترین راه)

#### در ویندوز (PowerShell):
```powershell
.\scripts\publish_to_github.ps1 "https://github.com/<نام-کاربری-شما>/RouterLink.git"
```

#### در لینوکس / مک (Bash):
```bash
chmod +x scripts/publish_to_github.sh
./scripts/publish_to_github.sh "https://github.com/<نام-کاربری-شما>/RouterLink.git"
```

---

### روش دوم: اجرای مرحله به مرحله دستورات Git در ترمینال

اگر می‌خواهید دستورات را به شکل دستی در ترمینال وارد کنید:

```bash
# ۱. ساخت مخزن گیت محلی و تنظیم برنچ اصلی
git init -b main

# ۲. اضافه کردن تمام فایل‌های پروژه (فایل‌های موقت طبق .gitignore نادیده گرفته می‌شوند)
git add .

# ۳. ثبت اولین کامیت انتشار نسخه v1.0.0
git commit -m "feat: initial production release of RouterLink v1.0.0"

# ۴. متصل کردن مخزن محلی به ریپازیتوری گیت‌هاب شما
git remote add origin https://github.com/<نام-کاربری-شما>/RouterLink.git

# ۵. ارسال کدها به برنچ main (شروع بیلد خودکار کانتینر داکر و اندروید)
git push -u origin main

# ۶. ثبت تگ ورژن v1.0.0 و ارسال آن به گیت‌هاب (ساخت خودکار صفحه Release و پیوست فایل APK)
git tag -a v1.0.0 -m "RouterLink v1.0.0 Release"
git push origin v1.0.0
```

### پس از ارسال چه اتفاقی می‌افتد؟
1. به صفحه گیت‌هاب پروژه بروید و روی تب **Actions** کلیک کنید:
   - فرآیند `Multi-Arch Docker Build` اجرا شده و ایمیج کانتینر روی رجیستری GHCR منتشر می‌شود.
   - فرآیند `Android APK Build` اجرا شده و سورس کد کاتلین کامپایل و فایل APK آماده می‌شود.
2. پس از پایان بیلد، به بخش **Releases** بروید؛ نسخه **v1.0.0** با فایل‌های آماده دانلود در انتظار شماست:
   - `RouterLink-Release.apk` (اپلیکیشن آماده نصب اندروید)
   - `routerlink-mikrotik-scripts.zip` (بسته اسکریپت‌های روتر او اس)
   - `install.rsc` (اسکریپت نصاب ۱ کلیکی)

## 🔒 پایداری داده‌ها و امنیت

- **حفاظت از اطلاعات کاربر**: کلیه اطلاعات کاربران، هش پسوردها (`bcrypt`) و کلیدهای خصوص پابلیک‌کی در فایل دیتابیس SQLite در مسیر روتر نگهداری می‌شوند (`/routerlink/data/routerlink.db`).
- **جداسازی کامل شبکه (Network Isolation)**: کانتینر در یک فضای شبکه مجازی اختصاصی (`veth-routerlink`) با دسترسی‌های حداقلی لینوکس (`NET_ADMIN` و `NET_RAW`) اجرا می‌گردد.
- **ترافیک رمزگذاری شده**: کلیه تبادلات وب با JWT امضا شده و تمامی نشست‌های فیلترشکن با پروتکل‌های استاندارد OpenVPN و WireGuard رمزنگاری می‌گردند.
